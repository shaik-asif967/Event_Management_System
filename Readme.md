# 📌 About

**EventTracker** is a front-end web application designed to simplify the management of college events.

The system provides dedicated interfaces for both **Students** and **Administrators**, allowing them to register for events, manage attendance, upload certificates, submit OD requests, and monitor event activities through an interactive dashboard.

The entire application is built using **HTML, CSS, JavaScript**, and **Browser Local Storage**, making it lightweight and easy to run without any backend.
